# SwiftDrop Documentation

This directory contains core reference documentation and specifications for the SwiftDrop project.

## Reference Documents

- **[SRS.md](file:///docs/SRS.md)**: Software Requirements Specification (v2.1). This document is the binding single source of truth across all functional requirements, data models, endpoints, business rules, and technical invariants.
- **[WORK_DIVISION.md](file:///docs/WORK_DIVISION.md)**: Work package breakdown and task allocations across the 10 team members. Note: File and package ownership defined in section 7 of `SWIFTDROP_MASTER_PROMPT.md` takes precedence over this file.
- **[UI_DESIGN_SYSTEM.md](file:///docs/UI_DESIGN_SYSTEM.md)**: UI visual design specifications (colors, typography, spacing, component styling). Used strictly for visual styling; does not introduce features or endpoints outside the SRS.
- **[SWIFTDROP_MASTER_PROMPT.md](file:///docs/SWIFTDROP_MASTER_PROMPT.md)**: Master developer and AI prompt governing cross-member coordination, conventions, technology constraints, and file ownership rules.

## Design and Reports

- `design/`: Topic-specific design notes and Mermaid diagrams authored by member slices.
- `audit/`: Architectural, infrastructure, and requirement audits (including Member #8 setup audit).
- `test-reports/`: Test verification logs and coverage reports.
