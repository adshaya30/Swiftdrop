## 3. SRS Gaps Identified
1. **Self-deactivation error code**: The SRS does not define a dedicated error code when an administrator attempts to deactivate their own account. Per `MEMBER_02.md`, return HTTP 403 `ACCESS_DENIED` and record as an SRS gap.
